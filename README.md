# Freakintosh
Macintosh based robotics and more!

## Projects

- [Shared Macintosh Plus motherboard hardware](projects/mac-plus-motherboard/HARDWARE.md):
  power, audio, internal SCSI, ROM upgrade, and Zip storage.
- [Smith Corona PWP 425 Macintosh conversion](projects/pwp-425-mac/README.md):
  adapt a Plus motherboard to the PWP chassis and retain its existing CRT.
- [Macintosh Plus serial GPIO interface](projects/mac-plus-gpio/README.md):
  a Pico 2 and SP3490 prototype for connecting sensors and control outputs to
  the Macintosh Plus printer port.

The repository supports several Macintosh projects, including a Macintosh
robot. Robot-specific requirements do not apply automatically to other builds.
